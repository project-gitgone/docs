**Syntax:** `gitgone COMMAND [SUBCOMMAND] [ARGS] [OPTIONS]`

Run `gitgone` alone for a guided menu, `gitgone help` for the grouped list of commands, and `gitgone <command> --help` for the arguments, options and examples of a command.

| Command | Description |
|---|---|
| [`login`](/docs/cli/commands/getting-started#login) | Sign in, or create the first administrator of a new server |
| [`init`](/docs/cli/commands/getting-started#init) | Link this folder to a project, or create one |
| [`status`](/docs/cli/commands/getting-started#status) | Show the server, account, project and keys in use here |
| [`whoami`](/docs/cli/commands/getting-started#whoami) | Show the account you are signed in with |
| [`logout`](/docs/cli/commands/getting-started#logout) | Forget the session and keys stored on this machine |
| [`pull`](/docs/cli/commands/secrets#pull) | Download and decrypt secrets into the local `.env` |
| [`push`](/docs/cli/commands/secrets#push) | Encrypt the local `.env` and send it to the server |
| [`run`](/docs/cli/commands/secrets#run) | Run a command with the secrets in its environment |
| [`history`](/docs/cli/commands/secrets#history) | List the versions of an environment |
| [`rollback`](/docs/cli/commands/secrets#rollback) | Restore a previous version as the latest one |

## Global options

Every command accepts these options.

| Option | Environment variable | Description |
|---|---|---|
| `--json` | — | Print the result as JSON, without colors or questions. Errors print `{ "error", "hint" }`. |
| `-y, --yes` | — | Accept every confirmation. Never trusts a new teammate's key. |
| `--server <url>` | `GITGONE_SERVER_URL` | Server to use for this run. |
| `--no-color` | `NO_COLOR` | Disable colors. |
| `-h, --help` | — | Show the help of the command. |
| `-v, --version` | — | Show the version of the CLI (`gitgone --version`). |

## Environment variables

| Variable | Description |
|---|---|
| `GITGONE_TOKEN` | A token from `gitgone token create`. `pull` and `run` then read its environment, without a session. See [Use GitGone in CI](/docs/cli/guides/ci). |
| `GITGONE_PASSWORD` | Your vault password, for commands that decrypt secrets without a terminal. |
| `GITGONE_SERVER_URL` | Server to use, before the `.gitgone` file and your global configuration. |
| `CI` | When set, the CLI never asks questions. |
| `NO_COLOR` | When set, the output has no colors. |
| `DEBUG` | `gitgone` prints the stack trace of errors. |
